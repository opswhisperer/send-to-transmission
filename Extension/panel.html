Get started

In Settings, enter your Transmission server address, port and RPC path (usually /transmission/rpc). Enable HTTPS if your server uses it, and login if the RPC server requires it. Save & test connection before sending links.

Right-click a download link

Choose Send to Transmission from the link’s context menu. The send page always opens so you can review the download directory and Add paused before pressing Send to Transmission.

For torrent files on the same website, this uses your logged-in Safari session. The link does not need to end in .torrent. The torrent file is sent to Transmission; your website cookies stay in Safari. Sign into the website first. Cross-site links and redirects are currently unsupported.

Send with a normal click

Enable Send normal clicks on magnet / .torrent links in Settings, or press Turn on in the toolbar popup. Recognizable torrent and magnet links open the send page. A link on the same website that describes itself as a torrent download (for example “Download torrent”) is fetched using your Safari login and sent if it really is a torrent, even when its address does not end in .torrent; otherwise the click works as usual. Other links with no recognizable torrent indicator still need right-click sending. Command, Shift and other modified clicks keep their normal behavior.

Click capture only works on pages Safari lets the extension see. The toolbar popup says whether it is working on the current page, and offers to allow website access or reload the page when it is not. A .torrent link to an address on your own network from a different website always opens the send page first.

Check Don’t show this page again on the send page before sending to skip it for future normal captured clicks. Your saved directory and Add paused default are used. Right-click sending always lets you review first, even with this option enabled.

For links ending in .torrent, normal click capture sends the URL to Transmission, which downloads it without your website login. If such a download needs a login, use right-click sending instead.

Magnet links everywhere else

Make Send to Transmission your Mac’s magnet link app by running scripts/magnet-handler.sh --set in Terminal from the source folder (the app shows which app has that role now). Magnet links from private windows, pages the extension is not allowed on, other browsers and other apps then go to your server too. The app also opens .torrent files from the Finder’s Open With menu. It uses the server and defaults saved here.

Paste a link

Open Send a link, paste a magnet link or public torrent URL, choose the options, then press Send to Transmission. Pasted URLs are fetched by your server and do not use Safari’s website login.

Choose a directory

Enter an absolute path on your Transmission server, such as /downloads/movies. Leave it blank to use Transmission’s default. Previously used directories appear as suggestions; this is not a browser for the server’s folders.

Send notifications

A notification appears at the top of the page as soon as you click, and updates when the send finishes. Success notices stay for 10 seconds; errors stay until you close them or a new notification replaces them. The toolbar badge shows OK for success or ! for an error. It clears when you open this panel or after 30 seconds. The latest result remains here below the tabs.

If something does not work

Open the toolbar popup on the page: it says whether click capture is on and working there. Allow the extension access to the website in Safari and reload the page after updating the extension. Read the displayed error; login pages and non-torrent responses cannot be sent. Use Save & test connection to check the RPC connection. HTTPS certificates must be trusted by your Mac.
