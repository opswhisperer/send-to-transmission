Get started

In Settings, enter your Transmission server address, port and RPC path (usually /transmission/rpc). Enable HTTPS if your server uses it, and login if the RPC server requires it. Save & test connection before sending links.

Right-click a download link

Choose Send to Transmission from the link’s context menu. The send page always opens so you can review the download directory and Add paused before pressing Send to Transmission.

For torrent files on the same website, this uses your logged-in Safari session. The link does not need to end in .torrent. The torrent file is sent to Transmission; your website cookies stay in Safari. Sign into the website first. Cross-site links and redirects are currently unsupported.

Send with a normal click

Enable Send normal clicks on magnet / .torrent links in Settings. Recognizable torrent and magnet links open the send page. Links with no recognizable torrent indicator still need right-click sending. Command, Shift and other modified clicks keep their normal behavior.

Check Don’t show this page again on the send page before sending to skip it for future normal captured clicks. Your saved directory and Add paused default are used. Right-click sending always lets you review first, even with this option enabled.

Normal click capture sends the URL to Transmission. For a torrent download requiring a website login, use right-click sending instead.

Paste a link

Open Send a link, paste a magnet link or public torrent URL, choose the options, then press Send to Transmission. Pasted URLs are fetched by your server and do not use Safari’s website login.

Choose a directory

Enter an absolute path on your Transmission server, such as /downloads/movies. Leave it blank to use Transmission’s default. Previously used directories appear as suggestions; this is not a browser for the server’s folders.

Send notifications

A notification appears at the top of the page after sending. Success notices stay for 10 seconds; errors stay until you close them or a new notification replaces them. The toolbar badge shows OK for success or ! for an error. It clears when you open this panel or after 30 seconds. The latest result remains here below the tabs.

If something does not work

Allow the extension access to the website in Safari and reload the page after updating the extension. Read the displayed error; login pages and non-torrent responses cannot be sent. Use Save & test connection to check the RPC connection. HTTPS certificates must be trusted by your Mac.
